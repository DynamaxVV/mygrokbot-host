# 变更记录

## 2026-10-22 — 桌面端与界面重构

### 桌面端（新增）

用 Electron 把 Web 客户端包成 macOS 应用，**没有第二套后端**：主进程即 gateway 的 Node 运行时。

- `desktop/main.mjs`：gateway 跑在系统分配的 loopback 端口，BrowserWindow 直接加载
- 托盘图标代码内绘制（模板图，无资源文件），关窗不退出（routines 需要进程活着）
- 单实例锁；外部链接交给系统浏览器；`hiddenInset` 标题栏，交通灯区域预留 30px
- 打包：245 MB `.app` / 112 MB DMG，其中本项目代码 1.2 MB

关键事实：Electron 41+ 自带 Node 24，`node:sqlite` 可用（实测 Electron 45 / Node 24.22），
所以不需要 sidecar。详见 [DESKTOP.md](DESKTOP.md)。

### 密钥管理（新增 `src/secrets.mjs`）

桌面版没有 shell 可以 export，因此密钥落在 `<dataRoot>/secrets/env.json`：

- 创建即 `0600`，写临时文件后 rename
- `loadSecretsIntoEnv()` 移到 `createHost()` 内部，CLI / 桌面 / gateway 行为一致
- binding 仍只存环境变量名，`getProviderConfig` 返回 `keyIsSet` 与掩码，不返回明文

### 设置面板（重做）

从「一个长列表」改为「左侧导航 + 右栏连续滚动」：

| 分区 | 内容 |
| --- | --- |
| 模型接入 | Base URL、模型 ID、API Key、密钥变量名、连接测试、保存 |
| 外观与语言 | 界面语言、气泡配色、时区 |
| 通知与网络 | 桌面通知、消息接收、外网隧道 |
| 自动审批 | 总开关、shell 策略、常驻放行、允许/拒绝规则 |
| 关于与维护 | 数据目录、端口、bot 数、版本、刷新技能、导出、重新加载 |

修复：`setHostSettings` 原来是浅合并，改嵌套字段会整个替换兄弟键，现在是递归深合并。

### 头像系统（重做）

- 头像 = SVG 轮廓（12 种：圆、方圆、水滴、菱形、花朵、胶囊、三角、五边、六边、盾、心…）+ 眼睛或自定义字符
- 容器透明，只有形状着色；群聊用成员头像叠放的圆形簇，各带白色描边
- 编辑器三个标签：Bot（形状 + 配色 + 文字）、生成（随机组合）、上传（图片，≤256KB）、重置
- 调色板按名册索引轮转，不再按 id 哈希（否则相邻 bot 撞色）

### 详情面板

- **双击编辑**：名称、职责、记忆；Enter 或失焦保存，Esc 取消
- 编辑态用绝对定位浮层 + 固定尺寸，**不改变任何布局**（`scrollHeight`、宽高全部不变）
- 角色区在面板底部：设为 / 替换 / 取消幕僚长，带二次确认

### 左栏

- 幕僚长置顶（紧凑横排），可设可换可取消；取消后无人担任且不保留分割线
- 群聊头像用成员叠放，单聊用单形状
- 搜索同时检索 **bot 与历史消息**，命中高亮；单击切 bot，双击跳到那条消息并闪烁定位

### 修复清单

| 缺陷 | 根因 |
| --- | --- |
| 附件路径 `workspace/workspace/` | 上传返回相对数据根，工具以工作区为根 |
| 中文文件名变下划线 | 正则里的 `\u4e00-\u9fa5` 被当字面量 |
| 命令面板无「导出」 | `commands` 非空时回退列表被跳过 |
| 进入会话时思考过程全展开 | 只有「有没有回答」一个判据，被中断的回合永远算进行中 |
| 右面板保存后不刷新 | 编辑器内的局部 `renderPane` 覆盖了全局同名函数 |
| 双击编辑导致布局跳动 | 边框/内边距改变了盒模型，且 `outline` 计入溢出 |
| 设置面板跳转只能向下 | `offsetTop` 受 `position: sticky` 影响 |
| 新增 bot 无反应 | `prompt()` 在 Electron 未实现，静默返回 null |
| 群聊头像稀疏 | 固定 2×2 网格，成员不足时留空象限 |
