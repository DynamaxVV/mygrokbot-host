# 变更记录

## 2026-10-22 — 执行、会话与可靠派工（P0/P1）

当前协议见 [EXECUTION.md](EXECUTION.md)，功能入口见 [CORE_FEATURES.md](CORE_FEATURES.md)，编译与启动见 [BUILD_AND_RUN.md](BUILD_AND_RUN.md)。以下旧章节按历史版本保留，旧 hidden 全局开关与群消息复制行为已经被本节替代。

- 增加主机级 `execution.db`（SQLite WAL/FULL），事务保存接纳、Run、交互、任务与 outbox。旧 JSON 台账兼容导入并用于诊断，Run 状态以协调库为准；已完成结果重启不回退，未知副作用结果进入 `needs-reconciliation`。
- 固定 `conversationId/runId/segmentId` 归属与输入水位，群业务历史仅群 Store 一份，不再复制成员私聊。逐条 hidden 属性替代 `store.hideWrites` 全局开关；私聊、群与任务记忆默认分区。
- Scheduler 取消等待真实退出，watchdog 宽限期后记 `stuck` 而非 escape 放行；`forceRelease` 请求取消，`drain` 等待任务与取消钩子。
- 审批与问题绑定原 Run、callId、参数摘要和取消版本；批准后的工具与续跑以同 Run 新 segment 排队。持久待决卡可恢复，无绑定旧卡过期；停止使对应交互失效。
- 群支持 fan-out、明确 @、coordinated 与 round_robin；轮次取消/替换/超时按精确成员 Run 操作，结果不再从最近一条 Bot 回复猜测。群投影使用稳定消息 ID 和持久投递去重。
- 增加本地 `delegate_task` 持久任务依赖，子任务独立会话执行、父等待释放槽、结果自动恢复父 Run。非本地目标返回明确错误；普通 `message_agent` 继续作为异步消息。
- 增加 `listTasks`、`getTask`、`cancelTask`、`getRunStatus`，台账诊断附执行库统计；查询、导出、分支与 SSE 按显示会话隔离。
- 此前完整回归 **174 项：171 通过、3 跳过**。本轮文档整理未新增 GUI、真实模型或打包验证；下文安装包大小和历史页面结果只对应当时验证。

## 2026-10-22 晚 — 群聊、@ 定向与隔离（历史实现）

### 群聊不再是"模型调用方"

给群聊发消息原来会走 `runTurn`，而群聊没有模型绑定，于是回落到内置默认地址并报
`provider 401 no-credentials`。现在 `postFromOperator()` 只做两件事：写进群聊记录、
把消息分发给成员。成员各自跑自己的回合，答完再把结果投回群里。

### 群聊与一对一完全隔离

群聊产生的每一行都带 `hidden`，成员自己的对话里不出现：

| 层 | 做法 |
| --- | --- |
| 写入 | 隐藏回合期间 `store.hideWrites = true`，所有行自动带 `hidden` |
| 上下文 | `buildMessages` 按**整轮**过滤（prompt/reasoning/tool/回答一起），只对本轮可见 |
| 事件 | `turn-start` 带 `hidden`，前端丢弃其实时事件 |
| 渲染 | `renderStream` 与名册预览都跳过 `hidden` |

被打断的回合另外标记 `partial`，提问和半截答案都不再回放——否则下一次发言会接着那个
没答完的问题继续写。

### @ 定向

- 输入框打 `@` 弹出补全：群聊列成员，单聊列其他 bot；↑↓ 选择，Tab/Enter 插入
- 多个 `@` 同时有效，按名字最长匹配（`@Nas Bot X` 不会误命中 `Nas Bot`）
- 被 @ 的成员回答，其余成员照常收到消息但不占用回合
- 服务端也解析 `@`，API 直接调用时行为一致

### 附件

- 位置改为气泡**上方**的独立媒体块，纯附件消息不再渲染空气泡
- 文件卡片整行可点，图标 + 文件名 + 省略号；时间戳落在卡片下方
- 群聊支持附件：群记录保留 `attachments`，成员收到的 prompt 附带文件路径
- 允许「只发附件、不写文字」

### 头像

- 群头像按成员数排布：2 人并排、3 人三角、4 人 2×2，超过 4 人统一为
  「三张脸 + 计数徽章」
- 成员保持各自轮廓并相互叠压，带底色描边
- 成员被删除时渲染占位而不是空格子

### 响应式与健壮性

| 缺陷 | 根因 |
| --- | --- |
| 窗口变窄后整体布局塌陷 | `≤1200px` 的媒体查询只声明 2 条网格轨道，3 个子元素被挤到第二行 |
| 821–900px 两侧面板消失且无法打开 | 一条遗留的 `≤900px` 规则隐藏了面板，覆盖层逻辑在 820px 才生效 |
| 缩小窗口后侧栏无法打开 | 按钮可见性只在加载时判断一次，改为监听断点变化 |
| 全左栏时间显示 `now` | 任意事件都会刷新 `lastActivityMs`，改为仅真实对话条目 |

### 其他修复

- 群成员回答被合并进同一气泡（`senderKey` 对所有 bot 返回同一个键）
- 被打断的回合永远显示「进行中」
- 只读/编辑态切换导致布局跳动
- `prompt()` 在 Electron 未实现，导致新建 bot 等按钮静默失效；改为内置表单弹窗
- 附件消息的 `ResizeObserver` 在气泡被移除后抛错
- 群聊唤醒时把工具调用过程写进正文


## 2026-10-22 — 桌面端与界面重构

### 桌面端（新增）

用 Electron 把 Web 客户端包成 macOS 应用，**没有第二套后端**：主进程即 gateway 的 Node 运行时。

- `desktop/main.mjs`：gateway 跑在系统分配的 loopback 端口，BrowserWindow 直接加载
- 托盘图标代码内绘制（模板图，无资源文件），关窗不退出（routines 需要进程活着）
- 单实例锁；外部链接交给系统浏览器；`hiddenInset` 标题栏，交通灯区域预留 30px
- 打包：245 MB `.app` / 112 MB DMG，其中本项目代码 1.2 MB

关键事实：Electron 41+ 自带 Node 24，`node:sqlite` 可用（实测 Electron 45 / Node 24.22），
所以不需要 sidecar。详见 [DESKTOP.md](DESKTOP.md)。

### 密钥管理（新增 `src/secrets.mjs`）

桌面版没有 shell 可以 export，因此密钥落在 `<dataRoot>/secrets/env.json`：

- 创建即 `0600`，写临时文件后 rename
- `loadSecretsIntoEnv()` 移到 `createHost()` 内部，CLI / 桌面 / gateway 行为一致
- binding 仍只存环境变量名，`getProviderConfig` 返回 `keyIsSet` 与掩码，不返回明文

### 设置面板（重做）

从「一个长列表」改为「左侧导航 + 右栏连续滚动」：

| 分区 | 内容 |
| --- | --- |
| 模型接入 | Base URL、模型 ID、API Key、密钥变量名、连接测试、保存 |
| 外观与语言 | 界面语言、气泡配色、时区 |
| 通知与网络 | 桌面通知、消息接收、外网隧道 |
| 自动审批 | 总开关、shell 策略、常驻放行、允许/拒绝规则 |
| 关于与维护 | 数据目录、端口、bot 数、版本、刷新技能、导出、重新加载 |

修复：`setHostSettings` 原来是浅合并，改嵌套字段会整个替换兄弟键，现在是递归深合并。

### 头像系统（重做）

- 头像 = SVG 轮廓（12 种：圆、方圆、水滴、菱形、花朵、胶囊、三角、五边、六边、盾、心…）+ 眼睛或自定义字符
- 容器透明，只有形状着色；群聊用成员头像叠放的圆形簇，各带白色描边
- 编辑器三个标签：Bot（形状 + 配色 + 文字）、生成（随机组合）、上传（图片，≤256KB）、重置
- 调色板按名册索引轮转，不再按 id 哈希（否则相邻 bot 撞色）

### 详情面板

- **双击编辑**：名称、职责、记忆；Enter 或失焦保存，Esc 取消
- 编辑态用绝对定位浮层 + 固定尺寸，**不改变任何布局**（`scrollHeight`、宽高全部不变）
- 角色区在面板底部：设为 / 替换 / 取消幕僚长，带二次确认

### 左栏

- 幕僚长置顶（紧凑横排），可设可换可取消；取消后无人担任且不保留分割线
- 群聊头像用成员叠放，单聊用单形状
- 搜索同时检索 **bot 与历史消息**，命中高亮；单击切 bot，双击跳到那条消息并闪烁定位

### 修复清单

| 缺陷 | 根因 |
| --- | --- |
| 附件路径 `workspace/workspace/` | 上传返回相对数据根，工具以工作区为根 |
| 中文文件名变下划线 | 正则里的 `\u4e00-\u9fa5` 被当字面量 |
| 命令面板无「导出」 | `commands` 非空时回退列表被跳过 |
| 进入会话时思考过程全展开 | 只有「有没有回答」一个判据，被中断的回合永远算进行中 |
| 右面板保存后不刷新 | 编辑器内的局部 `renderPane` 覆盖了全局同名函数 |
| 双击编辑导致布局跳动 | 边框/内边距改变了盒模型，且 `outline` 计入溢出 |
| 设置面板跳转只能向下 | `offsetTop` 受 `position: sticky` 影响 |
| 新增 bot 无反应 | `prompt()` 在 Electron 未实现，静默返回 null |
| 群聊头像稀疏 | 固定 2×2 网格，成员不足时留空象限 |
