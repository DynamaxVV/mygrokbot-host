# 功能验收记录

日期：2026-10-22。方法：Playwright 驱动真实 Chrome 操作页面，逐项断言 DOM 与 API 结果。

## P0 — 日常必用

| 功能 | 操作 | 结果 |
| --- | --- | --- |
| **附件上传** | 点 ＋ → 选文件 → chip 出现 → 发送 | chip 渲染 1 个；图片在气泡内显示，5 张全部 `naturalWidth > 0` |
| **附件被模型读取** | 上传 PNG 并问颜色 | 模型正确改用 `file`/`identify`，不再 `read_file` 读二进制 |
| **会话搜索** | ⌘F → 输入「协作边界」 | 36 条结果，36 处高亮；点击跳转到对应 bot 并关闭面板 |
| **会话导出** | ⌘K → 「导出当前对话」 | 浏览器下载 `主 Bot-<ts>.md`，内容 182KB |

## 本轮修掉的缺陷

| 缺陷 | 原因 | 修法 |
| --- | --- | --- |
| 附件路径 `workspace/workspace/uploads/` | 上传返回相对数据根的路径，工具以工作区为根 | 返回 `path.relative(p.workspace, …)`；三处兼容旧前缀 |
| 中文文件名变 `______.txt` | 正则里的 `\u4e00-\u9fa5` 被当字面量 | `\p{L}\p{N}` Unicode 属性类 |
| 模型把 PNG 当文本读 | 没告知文件类型 | 上下文标注「图片，不要用 read_file」 |
| 命令面板无「导出」 | `PALETTE_FALLBACK` 在 `commands` 非空时被跳过 | 本地命令始终追加 |
| 点命令无反应 | `runCommand` 只认 uimap 的 id | 支持 `cmd.run` 回调 |
| 分支重名 | 固定名 `X 分支` | 自动递增后缀 |
| `+ 新建` 按钮不渲染 | 替换目标不匹配 | 直接改真实模板串 |
